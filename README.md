# vanhoanhoang.github.io

Personal page. Plain HTML, no build step.

## Deploy

1. Repo name: `vanhoanHoang.github.io`.
2. Push to `main`. GitHub Pages serves the root automatically; check Settings > Pages if it doesn't.
3. Live at https://vanhoanhoang.github.io

## Custom domain (optional)

Add a `CNAME` file containing the domain, point a DNS CNAME record at `vanhoanhoang.github.io`, then enable "Enforce HTTPS" in Settings > Pages.
